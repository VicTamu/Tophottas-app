# TopShottas Apparel

Lean mobile storefront for an iOS-first clothing brand using Expo React Native, Shopify, and Firebase.

## Stack

- Expo
- React Native
- TypeScript
- Shopify Storefront API-ready services
- Firebase-ready app services
- Environment-based configuration

## Development

Install dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npm start
```

## Configuration

Copy `.env.example` to `.env` and add the required storefront values when connecting live commerce data.

```bash
cp .env.example .env
```

## Notes

This repository contains the mobile app source for an active client project. Product data, credentials, and launch-specific configuration should remain outside source control.
